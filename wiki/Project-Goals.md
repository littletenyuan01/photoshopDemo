# 项目目标

## 定位

做一个**能完整演示关键图像编辑链路**的 Qt 桌面应用，用于：

- 简历项目经历
- 面试时讲解架构与实现取舍
- 练习大型桌面软件的模块划分

## 硬约束

| 约束 | 说明 |
|------|------|
| 代码量 | **不超过约 7 万行** |
| UI | **Qt Widgets**（现有 `psDemo`） |
| 参考 | 学习 GIMP 的分层思路，不搬运其代码 |
| 完成标准 | 关键链路可演示，而非功能清单堆满 |
| 加速库 | **允许** OpenCV、CUDA、CPU 并行；无 GPU 时主链路可 CPU 回退 |

## 做什么

- 打开 / 新建图像
- 图层（增删、显隐、透明度、简单混合）
- 基础绘制工具（如画笔、橡皮）
- 撤销 / 重做
- 导出常见格式（如 PNG / JPEG）
- 主界面分区：菜单、工具栏、画布、图层面板等

## 刻意不做（v1 / 默认范围）

- Photoshop 全功能（完整调整层、印刷 CMYK、动作批处理等）
- 完整 PSD 特性兼容（当工业级交换格式）
- GIMP 的 GEGL / PDB / 完整插件宿主照搬
- 过度打磨视觉主题（够用、清晰即可）

## 有余力可选（stretch，已记入路线图）

v1 **不承诺**；链路与简历打磨完成后、代码量仍有余量时可排期。详见 [Roadmap Phase 5](Roadmap.md)。

1. **PSD 导入 / 导出**（简版分层读写）
2. **智能对象**（嵌入位图 + 再栅格化合成）
3. **插件库**（极简扩展点，非完整宿主）

## 成功标准（简历向）

1. 克隆仓库后能按 Wiki 编译运行  
2. 一条演示路径从打开到导出全程可走通  
3. 能讲清：文档模型、图层合成、工具与像素写入、撤销栈如何协作
