# 功能链路（演示闭环）

本项目的「完整」指**链路完整**，不是功能数量完整。

## 最小可演示闭环（v1）

```text
新建/打开图像
    → 管理图层（新建 / 删除 / 显隐 / 透明度 / 混合）
    → 选区（矩形/椭圆/套索）约束绘制与填充
    → 选择工具编辑（画笔 / 橡皮 / 油漆桶 / 渐变）
    → 编辑→清除 / 填充（Delete / Shift+F5）
    → 画布实时预览（图层合成结果）
    → 撤销 / 重做（Ctrl+Z / Ctrl+Y）
    → 导出 PNG 或 JPEG（或存储 .pslite）
```

任一环缺失，都不算链路完成。

## 每环验收标准

| 环节 | 验收 |
|------|------|
| 打开/新建 | 能得到可编辑的文档（宽高、背景层）；主页最近文件可打开 |
| 图层 | UI 与数据一致；改透明度/显隐/混合立即反映到画布 |
| 选区 | 全选/取消/反选；绘制与填充只改 mask 内 |
| 绘制 | 只画在当前活动层；橡皮可擦除该层像素 |
| 清除/填充 | Delete 清选区或整层；Shift+F5 用前景色填选区或整层；可撤销 |
| 合成预览 | 多图层叠放结果正确（PS 27 种混合 + 透明度） |
| 撤销/重做 | 绘制、填充、清除与图层操作可回退/前进 |
| 导出 | 导出为合成后的位图文件（PNG/JPEG） |

## 自测脚本（约 3 分钟）

按顺序点一遍；任一步失败即记 bug，勿跳过。

1. **启动** → 应落在主页（非空白画布）；点「新建」建 800×600 文档，进入工作区。
2. **缩放** → 适应窗口后画布居中；滚轮缩放；空格拖平移；≥500% 可见像素网格。
3. **图层** → 新建透明层；改名；拖不透明度；切混合模式（悬停预览、点选提交）。
4. **绘制** → 画笔涂几笔；`[` / `]` 改大小；橡皮擦一部分；`X` 交换前景/背景，`D` 复位黑白。
5. **选区** → 矩形选一块；画笔只画在选区内；`Ctrl+A` / 取消选择 / 反选各试一次。
6. **填充/清除** → 再拉选区 → `Shift+F5` 前景色填充 → `Ctrl+Z` 撤销 → `Delete` 清除选区 → 再撤销。
7. **油漆桶/渐变** → 容差填充；渐变拖一条；有选区时只改选区内。
8. **移动** → `V` 点非透明像素换活动层并拖偏移。
9. **撤销栈** → `Ctrl+Z` / `Ctrl+Y` 来回几次，图层面板与画布一致。
10. **导出** → 文件→导出为… 存 PNG；再存一份 JPEG；用系统看图确认是合成结果。
11. **工程** → `Ctrl+S` 存 `.pslite`；关闭后从主页最近文件或打开，图层仍在。

> 蒙版 / 调整层 **不在**本脚本内（Roadmap Phase 8 / stretch）。
