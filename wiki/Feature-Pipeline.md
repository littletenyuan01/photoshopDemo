# 功能链路（演示闭环）

本项目的「完整」指**链路完整**，不是功能数量完整。

## 最小可演示闭环（v1）

```text
新建/打开图像
    → 管理图层（新建 / 删除 / 显隐 / 透明度）
    → 选择工具编辑（画笔 / 橡皮）
    → 画布实时预览（图层合成结果）
    → 撤销 / 重做
    → 导出 PNG 或 JPEG
```

任一环缺失，都不算链路完成。

## 每环验收标准

| 环节 | 验收 |
|------|------|
| 打开/新建 | 能得到可编辑的文档（宽高、背景层） |
| 图层 | UI 与数据一致；改透明度/显隐立即反映到画布 |
| 绘制 | 只画在当前活动层；橡皮可擦除该层像素 |
| 合成预览 | 多图层叠放结果正确（至少支持 Normal + 透明度） |
| 撤销/重做 | 绘制与图层操作可回退/前进 |
| 导出 | 导出为合成后的位图文件 |

## 后续可增强（非 v1 必做）

- 更多混合模式
- 选区 / 填充
- 简单色彩调整（亮度对比度等）
- 项目文件自有格式（含图层信息）

## 有余力可选（stretch，已记录待排期）

以下三项**不阻塞**演示闭环与简历验收；仅在 v1 稳、仍有开发余力时考虑。详见 [开发路线 Phase 5](Roadmap.md)。

| 目标 | 期望（简版） | 明确不做 |
|------|--------------|----------|
| PSD 导入 / 导出 | 常见分层 PSD 读写；图层像素 + 显隐/透明度 | 完整 PS 特性 / 完美兼容 |
| 智能对象 | 可嵌入位图、替换内容、变换后再栅格化合成 | PS 全套智能滤镜 / 链接资源生态 |
| 插件库 | 极简扩展点（滤镜或导出钩子） | GIMP PDB / 完整插件宿主 |
