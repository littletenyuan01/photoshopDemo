# 简历 / 面试话术（草稿）

## 一句话介绍

基于 Qt 实现的轻量仿 Photoshop 图像编辑器：支持多层编辑、基础绘制、撤销重做与导出，参考 GIMP 做模块分层，控制在较小代码规模内完成可演示闭环。

## 可写的技术点

- Qt Widgets 桌面 UI（主窗口、画布、图层面板）
- 图像文档模型与图层合成
- 工具层与像素绘制分离
- 撤销栈（命令或快照）
- 参考开源架构做简化落地，而非堆砌功能

## 面试时建议强调

1. **为什么砍功能**：简历项目要链路完整、可讲清，而不是仿到 1:1  
2. **参考了什么**：GIMP 的 core / paint / tools 分层；自己用 Qt + `QImage` 简化  
3. **你独立完成了什么**：模型、合成、工具、撤销、IO、界面联调  

## 暂勿夸大

- 不要写「完整兼容 Photoshop / PSD」  
- 不要写「实现了 GIMP 全部内核」
