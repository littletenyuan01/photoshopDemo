# 简历 / 面试话术

## 一句话介绍

基于 Qt 实现的轻量仿 Photoshop 编辑器：多层文档 + 选区约束绘制 + 推入式撤销 + PNG/JPEG 导出，参考 GIMP 分层，在可控代码量内跑通可演示闭环。

## 项目经历可写（示例）

> 独立设计并实现 Qt 桌面图像编辑 Demo（PhotoshopLite）：自研文档/图层模型（64×64 瓦片）、27 种混合模式合成、工具层与像素引擎分离；对照 GIMP 采用推入式历史栈；支持选区、工程格式 `.pslite` 与栅格导出。强调架构取舍与链路完整，而非复刻 PS 全功能。

## 可讲的技术点

| 点 | 怎么讲 |
|----|--------|
| 分层 | `domain` 真相、`engine` 算法、`tools` 状态机、`ui` 只订阅 `AppSession` |
| 瓦片 | 透明层零分配；绘制按需占块（对照 GIMP/GEGL 懒瓦片语义） |
| 合成 | 自底向顶 + 预乘 Alpha；混合模式与 PS 对齐的子集实现 |
| 撤销 | **改之前 push**；四类 UndoItem（像素 / 属性 / 结构 / 几何），非万能命令模式 |
| 选区 | 文档级 mask；绘制 / 填充 / 清除统一裁剪 |
| IO | 扁图导出 vs `.pslite` 保层；PSD 仅子集写出，诚实标注边界 |

## 面试时建议强调

1. **为什么砍功能**：简历要链路完整、能讲清，不是功能清单堆满  
2. **参考了什么**：GIMP 的 undo-push / 图层 / 工具分层；用 Qt + `QImage` 落地，不搬 GObject/GEGL  
3. **你独立完成了什么**：模型、合成、工具、历史、IO、界面联调与文档  
4. **下一步会做什么**：脏区分块投影（Phase 7）、调整层节点（Phase 8）——知道债在哪

## 演示怎么带（约 3 分钟）

按 [Feature-Pipeline 自测脚本](Feature-Pipeline.md) 或 [Demo.md](Demo.md) 走：新建 → 多层涂抹 → 选区填充 → Ctrl+Z → 导出。  
原理深讲可打开 `presentations/` 离线稿（瓦片 / 图像引擎）。

## 暂勿夸大

- 不要写「完整兼容 Photoshop / PSD」  
- 不要写「实现了 GIMP 全部内核 / GEGL」  
- 不要写「工业级非破坏调整层」（Phase 8 未做）  
- 通道 / 路径面板多为 UI 推算占位，面试被问到要主动说明
