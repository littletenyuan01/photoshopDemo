# 演示说明（简历 / 面试）

面向展示：先跑通闭环，再按需展开架构。完整手测清单见 [Feature-Pipeline.md](Feature-Pipeline.md)。

## 30 秒电梯稿

「这是一个 Qt 仿 PS 的轻量编辑器。文档和图层在 domain，画笔写瓦片，合成 27 种混合；撤销对照 GIMP 推入式。今天演示从新建画到导出。」

## 3 分钟操作路径

1. 启动 → 主页「新建」→ 进入工作区  
2. 新建一层 → 画笔涂几笔 → `[` / `]` 改大小  
3. 矩形选区 → `Shift+F5` 前景色填充 → `Delete` 清除 → `Ctrl+Z` 撤销  
4. 改图层不透明度 / 混合模式，看画布即时变化  
5. 文件 → 导出为… → PNG；可选再 `Ctrl+S` 存 `.pslite`

## 讲解时可指的界面

| 区域 | 说什么 |
|------|--------|
| 工具箱 + 选项栏 | 工具是状态机，画布不写 `if (brush)` |
| 画布 | 合成结果；透明棋盘格；高倍像素网格 |
| 图层面板 | 与 `ImageDocument` 同源；缩略图停笔刷新 |
| 状态栏路径 | 未保存 `*`；导出不改工程脏标记 |

## 常被追问

| 问题 | 短答 |
|------|------|
| 和 PS 差在哪？ | 无蒙版/调整层/智能对象；菜单大量灰显占位 |
| 撤销占多少内存？ | 整层快照 + 栈上限丢最老；脏矩形优化后置 |
| 为什么不用命令模式？ | 对齐 GIMP push：改前存旧状态，漏入口即 bug |
| 为何有通道面板？ | UI 壳对齐 PS；分量图由合成结果推算，无独立 Channel domain |
