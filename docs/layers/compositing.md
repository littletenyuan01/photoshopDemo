# 合成、透明度与视图刷新

## 1. 合成器做什么

`Compositor` **只读**各层像素，输出一张预览图，不修改层数据。

流程（本项目 v1）：

1. 建一张与文档同大的**临时结果图**，先填透明  
2. 自底向顶遍历可见层  
3. 用 Normal + 不透明度做逐像素混合  
4. 返回结果；`CanvasView` 再按缩放画到屏幕（棋盘格表示透明）

不是矢量「布尔挖洞」，而是 **Alpha 混合**：半透明会透出下层颜色。

## 2. 小例子

文档 4×3，背景全白；上层 2×2 不透明红，贴在右上：

```
结果：
W W R R
W W R R
W W W W
```

若上层红且 **α=50%**：那 4 格是粉红（红与白各半），不是把白挖掉。

## 3. 混合公式（标明上 / 下）

直通 Alpha 形式（颜色 0~1）：

\[
结果 = 上 \times α_{上} + 下 \times (1 - α_{上})
\]

- **上**：正在盖上去的当前层（该像素）  
- **下**：临时结果里已有内容（更底层已混入）  
- **α上**：该像素有效不透明度  

预乘形式（RGB 已含 α）与之等价，实现更直接：

\[
结果 = 上_{预乘} + 下_{预乘} \times (1 - α_{上})
\]

见 `psDemo/engine/compositor.cpp` 中 `blendNormalPremultiplied`。

## 4. 两种「透明度」

| 种类 | 含义 |
|------|------|
| **像素 Alpha** | 每个像素 RGBA 里的 A；软笔边缘、橡皮、透明层靠它 |
| **图层不透明度** | 面板滑条；合成时整层再乘：`有效 α ≈ 像素A × 图层不透明度` |

新建透明层：多数像素 A=0；白背景层：像素多为不透明白。  
图层滑条不能代替「有的像素有色、有的全透」。

**预乘**：存储时 RGB 已 × 像素 α（`Format_ARGB32_Premultiplied`）。与「图层不透明度滑条」不是同一件事；滑条是合成时额外乘一次。

## 5. 改一层后如何刷新

```
改图层（画 / 移 / 显隐 / 透明度）
  → 更新文档数据（必要时 markDirty）
  → 合成器生成/更新合成图（全图或脏区）
  → 视图按当前缩放显示
```

- **朴素（本 Demo）**：从底到顶再合成（可限脏矩形）。  
- **优化（PS/GIMP）**：缓存下方已合成结果，动中间层时尽量只重算**该层及以上**。  
  不是「只算上一层和下一层」——上面各层通常都要再盖；下面可靠缓存跳过。

**文档是真相**；合成图是中间结果；视图是显示器。不是改完只生成视图、跳过文档。

## 6. 视图缩放 vs 合成

合成在**图像像素坐标**里完成；滚轮缩放只改变 `CanvasView` 如何把合成图画到窗口（本项目放大较多时关闭平滑插值，像素块更利落）。
