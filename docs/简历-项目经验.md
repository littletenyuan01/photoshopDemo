## 一句话项目描述（可直接改写）

> 基于 **Qt Widgets** 的桌面图像编辑器教学工程：自研 **文档/图层/稀疏瓦片** 模型与 **脏区合成**，工具层改真相、会话广播刷新；含选区、撤销、非破坏滤镜、可选 **瓦片页缓存** / **GPU 栅格加速**、`.pslite` 工程与钢笔路径（至 ProjectFormat v4）。

---

## 简历条目模板（选择 3～5 条真实做过的）

按你实际贡献勾选，数字与模块名以当前代码为准：

1. **分层架构**：`ui → app → tools/domain/engine`；`AppSession` 独占文档并用 `documentChanged` 广播，避免 MainWindow 手工扇出。  
2. **文档模型**：`ImageDocument` + 稀疏 `TileBuffer`（64×64）+ 语义化图层 API；像素/属性变更经 `markDirty` 驱动刷新；复制层走 `sharePixelsFrom`（QImage COW）。  
3. **画布合成**：`Projection` 分块 + 时间预算调用 `Compositor::compositeRegion`，支撑局部重绘。  
4. **工具管线**：`ToolManager` 分发 `ToolEvent`；画笔经 `PaintEngine` 写瓦片并先 `push*Undo`。  
5. **选区 / 历史 / 内存**：文档级 mask；`HistoryStack` 字节上限；可选 `TileCache` 页缓存（默认关，静默点 trim）。  
6. **钢笔路径（P0–P4）**：Bezier 路径域模型、填充/描边、Pen/锚点工具、`PathStack`/`PathUndo`、选区互转、工程格式 v4 持久化。  
7. **滤镜与调度**：图层 `FilterStack` 非破坏求值；`RasterScheduler` CPU/GPU 可选加速与回退。  
8. **工程 IO**：`.pslite`（`PSLT` + `ProjectFormat::Current`）；滤镜参数固定块预留，避免频繁升版。  
9. **质量**：无 GUI 常驻测试 `psdemo_tests`（`opsInit` 后按用例过滤）。

## 面试口述骨架（60～90 秒）

1. **场景**：要做一个可扩展的 PS-like 编辑器，而不是 Demo 窗口直接改 QImage。  
2. **结构**：文档是真相；工具写文档；合成只读；会话广播。  
3. **一点深水**：举你最熟的一条——例如脏区 Projection、或钢笔 PathStack 与 v4 IO、或 Scheduler 回退。  
4. **结果**：能指出对应目录/类名；能说测试怎么跑。  
5. **边界**：诚实说未做项（见 `filter-roadmap` / `pending-dev`），避免被追问穿帮。

## STAR 素材槽（自己填具体 diff）

| 情境 | 任务 | 行动 | 结果 |
|------|------|------|------|
| 加面板要改十处 setDocument | 解耦文档分发 | 引入 AppSession 广播 | 新面板只订阅信号 |
| 全图合成卡顿 | 局部刷新 | dirty + Projection chunk | 涂抹跟手 |
