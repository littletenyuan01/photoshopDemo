# 功能说明

> 只写真实进度。未做功能标「计划中」。

## 已实现

### 主窗口壳

- **说明**：应用启动后显示主窗口（菜单栏 / 状态栏占位，中央区为空）。
- **如何用**：Qt Creator 打开 `psDemo/psDemo.pro` 运行即可。
- **限制**：尚无画布、图层、工具。

## 计划中（v1 闭环）

| 功能 | 简介 | 验收要点 |
|------|------|----------|
| 新建 / 打开 | 创建空白文档或载入位图 | 得到可编辑文档 |
| 图层 | 增删、显隐、透明度 | UI 与画布一致 |
| 画笔 / 橡皮 | 在活动层绘制或擦除 | 不污染其他层 |
| 合成预览 | 多层 Normal + 透明度 | 画布显示最终效果 |
| 撤销 / 重做 | 绘制与关键图层操作可回退 | 栈行为正确 |
| 导出 | PNG / JPEG | 导出为合成结果 |

细节实现后，在本文件为每项增加「用法 / 限制 / 相关文档」小节。
