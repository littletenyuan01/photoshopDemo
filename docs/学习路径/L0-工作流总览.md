# L0 — 工作流总览

**目标：** 用「用户从打开软件到导出文件」串起仓库，而不是先背架构名词。

**建议耗时：** 25～40 分钟。

---

## 1. 用户主路径（本学习路径的脊梁）

```text
① 启动 PSLite
② 新建空白图 或 打开 .pslite / 图片 / PSD
③ 在画布上看到图层合成结果
④ 选工具 → 绘制 / 变换等，改像素或属性
⑤ 不满意 → 撤销 / 重做
⑥ 需要时：选区、调图层、滤镜、钢笔路径
⑦ 保存工程 或 导出位图
```

每一层学习文档对应上面一步（或一组操作）。  
读代码时始终问：**用户刚做了什么？数据从哪进、哪出、谁刷新屏幕？**

---

## 2. 工作流 ↔ 代码落点（先建立形状）

| 步骤 | 用户动作 | 优先去哪 |
|------|----------|----------|
| ① | 启动 | [`main.cpp`](../../psDemo/main.cpp) |
| ② | 新建/打开 | `MainWindow` 菜单 → [`AppSession`](../../psDemo/app/appsession.h) → `ImageDocument` / `ProjectIo` |
| ③ | 看见画面 | [`CanvasView`](../../psDemo/ui/canvasview.h) → `Projection` → [`Compositor`](../../psDemo/engine/compositor.h) |
| ④ | 绘制 | [`ToolManager`](../../psDemo/tools/toolmanager.h) → 工具 → `PaintEngine` → `Layer::tiles` |
| ⑤ | 撤销 | [`HistoryStack`](../../psDemo/app/historystack.h) |
| ⑥a | 选区 | [`Selection`](../../psDemo/domain/selection.h) |
| ⑥b | 调图层 | `ImageDocument` 语义化 setter + 图层面板 |
| ⑥c | 滤镜 | `FilterStack` → 求值（加速见 L11） |
| ⑥d | 钢笔 | `PathStack` / `PenTool` |
| ⑦ | 保存/导出 | [`ProjectIo`](../../psDemo/io/projectio.h) / `RasterIo` / `PsdIo` |

架构依赖（记一句即可）：`ui → app → tools/domain`，`domain/engine` **不得**依赖 Widgets。

## 3. 四条故事线（面试串讲用）

| 线 | 用户感知 | 贯穿哪些步 |
|----|----------|------------|
| 编辑 | 画上去、改属性 | ④⑥ |
| 撤销 | Ctrl+Z | ⑤（服务所有编辑） |
| 选区 | 蚂蚁线、只改一块 | ⑥a |
| 存盘 | 关掉再开还在 | ②⑦ |
