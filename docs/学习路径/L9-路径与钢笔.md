# L9 — 路径与钢笔

**用户在干什么：** 用钢笔/自由钢笔画路径；在路径面板管理；路径⇄选区；填充/描边路径。

**目标：** Path 是矢量真相；工具如何 commit；`pushPathUndo`；与选区互转。

**建议耗时：** 60～90 分钟。  
**前置：** [L6](./L6-选区操作.md)、[L5](./L5-撤销与重做.md)。
