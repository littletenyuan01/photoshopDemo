# L11 — 进阶：GPU 加速

**用户在干什么：** 通常**无感**。滤镜/栅格链在有独显时更快；没有则仍应能用。

**目标：** GPU = **可选加速后端**，不是产品主流程某一步；`RasterScheduler` 探测、选型、回退。

**建议耗时：** 40～50 分钟。  
**前置：** [L8-滤镜操作](./L8-滤镜操作.md)、[L1](./L1-启动新建与打开.md) 里的 `warmUp`。

> 本层**不在**「新建→导出」主链上。做滤镜性能、后端、简历里「GPU」口径时再读。

---

## 1. 为何单独一层

| 模块 | 用户问题 |
|------|----------|
| L8 滤镜 | 效果对不对、挂在哪 |
| L11 GPU | 算得快不快、没显卡能不能用 |
| L10 存盘 | 能否下次打开 |

三者会在运行时相交，但学习/排错要先分清。

---

## 2. 代码落点

```text
main → RasterScheduler::warmUp()     // 异步，禁主线程 sleep
     → probe → backend = gpu | cpu
滤镜等 → runStack → rastercost 参与决策 → 失败回退 CPU
```

读：`rasterscheduler.h`、`rasterbackend.h`、`rastercost.*`。  
gpu-plan.md 只读「可选加速 / 硬约束」定位，禁止当通读作业。
