# L7 — 图层操作

**用户在干什么：** 新建/删除/排序图层；改可见性、不透明度、混合模式、改名；移动图层。

**目标：** 这些操作必须走 `ImageDocument` 语义化 API（可广播、可进撤销），而不是 UI 直接拧 `Layer` 私货。

**建议耗时：** 45～60 分钟。  
**前置：** [L2](./L2-认识文档与图层.md)（模型）、[L5](./L5-撤销与重做.md)。

---

## 1. 工作流位置

```text
已有文档模型（L2）
  → [本层] 用户在图层面板里「操作图层」
```

---

## 2. 代码落点

| 用户动作 | 优先入口 |
|----------|----------|
| 显隐 / 透明度 / 名字 / 混合 | `ImageDocument::setLayerVisible` 等 |
| 平移图层 | `translateLayer` 等 |
| 结构变化（增删排序） | Document / LayerStack 结构 API + 对应 undo |
| 面板展示 | 图层面板订 `documentChanged` / 图层变更信号 |

属性变更 → 通知 → 脏区/重合成（回 L3）。  
蒙版、样式若已接好，同样经 Document，不要绕过。

---

## 3. 建议阅读步骤

1. `imagedocument.h` 所有 `setLayer*` / 结构操作 / `push*Undo`。  
2. 图层面板（dock）槽函数如何调到 Document。  
3. 改一处透明度：从点击跟到 `markDirty` 或属性变更信号。  
4. 对照 L2：数据在 Layer 上，**写入权**在 Document。
