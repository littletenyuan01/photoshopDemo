# L10 — 保存与导出

**用户在干什么：** 保存 `.pslite` 工程；或导出 PNG/JPEG 等；有时读写 PSD 子集。

**目标：** 分清「工程保存」与「位图导出」；`ProjectFormat::Current` 政策；打开失败时怎么判断。

**建议耗时：** 45～60 分钟。  
**前置：** [L1](./L1-启动新建与打开.md)（打开对称）、建议已走过 L6～L9（知道选区/路径/滤镜会落盘）。

---

## 1. 工作流位置（主流程收官）

```text
编辑完成
  → [本层] 保存工程 或 导出图片
  → 之后可再「打开」（回到 L1）
```

GPU **不是**保存步骤；性能进阶见 [L11](./L11-进阶-GPU加速.md)。

---

## 2. 代码落点

| 用户动作 | 模块 |
|----------|------|
| 保存/打开工程 `.pslite` | [`ProjectIo`](../../psDemo/io/projectio.h)，魔数 `PSLT`，`ProjectFormat::Current`（现为 **4**，含路径） |
| 导出/打开普通图片 | `RasterIo` |
| PSD 子集 | `PsdIo` |

政策：

- **只认 Current**，不做跨版本兼容；格式不符 → 加载失败（明示）。  
- 滤镜参数：**固定字节块 + 预留**；预留用尽再升 Format。  

`MainWindow` 按扩展名选 IO → 成功则 `AppSession::setDocument`（打开）或写文件（保存）。

常驻测试入口（验证各模块，收官时学会跑）：[`tests.md`](../tests.md)、`psDemo/tests/testmain.cpp`。

---

## 3. 建议阅读步骤

1. `projectio.h` 的 `ProjectFormat` 注释。  
2. `save`/`load` 段序：头 → 层 → 选区 → 路径。  
3. MainWindow 保存/导出/打开分支。  
4. 跑一次 `psdemo_tests.exe projectio`。
