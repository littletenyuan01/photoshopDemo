# PhotoshopLite 学习路径（按用户工作流）

跟代码的顺序 = **用户怎么用这款软件**：

```text
启动 → 新建/打开文档 → 看见画面 → 绘制 → 撤销
     → 选区 → 调图层 → 滤镜 → 钢笔路径 → 保存/导出
```

架构分层（`ui → app → domain/tools/engine`）仍然重要，但**带路不按架构切课**，而按上面这条工作流。  
**也不按「功能开发先后」加附录**：后做的能力（页缓存、GPU…）在用户**第一次碰到该现象**时引入。

## 怎么用

1. 打开某一层 `.md`，**Ctrl+单击**跳到源码。  
2. 每层结构：用户在干什么 → 代码落点 → 阅读步骤 → 必读/选读 → 误解 → 自检 → 怎么测。  
3. **自检过关再进下一层**；禁止一上来通读 `mainwindow.cpp` / 整棵 `engine/op/`。  
4. **跟 AI 分段学**：进度见 [学习进度记录.md](./学习进度记录.md)；每段读完回复「阅读完成」；要点进 `Lx-知识笔记.md`；一层完了出测验。跨层调用链见 [业务流追踪.md](./业务流追踪.md）。
5. **笔记写法三要素**：每次落笔记 `Lx-知识笔记.md`，必须同时具备——
   - **架构**（结构图/层级图，体现「谁装谁、谁持谁」）；
   - **调用关系**（谁调谁、信号/入口链）；
   - **代码支撑**（真实函数签名/关键行，可回链到源码）。
   缺一不算合格的笔记，某要素当时没有则可留空待补，但要在该节标注。
6. **新增 `docs/` 参考文档时，必须同时在本文件的「横切主题」或「随时可翻」表里登记入口**（写清"用户第一次会在什么现象下需要它"）；值得系统跟读的另立 `专题-<主题>.md`（只写入口/不变量/事故/自检题，细节指向参考文档）。理由见 [缺口盘点-2026-10](./缺口盘点-2026-10.md) 与 `.cursor/rules/docs-and-commit.mdc`。

| 层 | 用户在干什么 | 文档 | 建议耗时 |

| 3 | 在画布上看到合成结果（投影也占内存） | [L3-画布显示与合成](./L3-画布显示与合成.md) | 60～90 分 |

| 8 | 给图层加滤镜（派生缓存） | [L8-滤镜操作](./L8-滤镜操作.md) | 45～60 分 |
| 9 | 钢笔路径、路径与选区互转 | [L9-路径与钢笔](./L9-路径与钢笔.md) | 60～90 分 |

| 考 | 闭卷检验 | [测验-工作流.html](./测验-工作流.html) | 20～30 分 |

主流程是 **L0→L10**（新建到导出）。**L11 可跳过**。页缓存**没有 L12**——跟内存一起嵌在 L2～L5/L7/L8。  
**并发**、**几何变换**、**算子协议**、**图引擎**同样**没有 L12**：它们是横切主题，各有一份**专题**文档（见上表），**按现象查阅**，不计入主线进度。
