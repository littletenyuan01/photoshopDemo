# PhotoshopLite 学习路径（按用户工作流）

跟代码的顺序 = **用户怎么用这款软件**：

```text
启动 → 新建/打开文档 → 看见画面 → 绘制 → 撤销
     → 选区 → 调图层 → 滤镜 → 钢笔路径 → 保存/导出
```

架构分层（`ui → app → domain/tools/engine`）仍然重要，但**带路不按架构切课**，而按上面这条工作流。  
**也不按「功能开发先后」加附录**：后做的能力（页缓存、GPU…）在用户**第一次碰到该现象**时引入。

### 横切主题怎么出现（全局观）

| 主题 | 用户第一次会碰到时 | 落在哪一层（不是单独新课） |
|------|--------------------|----------------------------|
| 稀疏瓦片 / 像素真相 | 弄清「图里有什么」 | **L2** |
| 投影缓冲 / 分块合成 | 看见画面、拖动画布 | **L3** |
| 瓦片随笔触增长 / 静默点 | 画笔涂抹 | **L4** |
| 撤销内存上限 | Ctrl+Z、历史很长 | **L5** |
| 复制图层与 QImage COW | 图层面板「复制」 | **L7** |
| 可重算的滤镜区域缓存 | 加滤镜预览/定稿 | **L8** |
| **页缓存换页**（默认关） | 大图/多层内存吃紧时 | 穿插 **L2 预告 → L3/L4 静默点 → L5 对照**；细节见 [page-cache-plan](../page-cache-plan.md) |
| GPU 可选加速 | 滤镜算得慢 | **L11**（进阶，可跳过） |

`architecture.md` / `code-map.md` 是参考库；本目录负责带路。

## 怎么用

1. 打开某一层 `.md`，**Ctrl+单击**跳到源码。  
2. 每层结构：用户在干什么 → 代码落点 → 阅读步骤 → 必读/选读 → 误解 → 自检 → 怎么测。  
3. **自检过关再进下一层**；禁止一上来通读 `mainwindow.cpp` / 整棵 `engine/op/`。

## 进度总览

| 层 | 用户在干什么 | 文档 | 建议耗时 |
|----|--------------|------|----------|
| 0 | 看清整条工作流（含内存故事线） | [L0-工作流总览](./L0-工作流总览.md) | 25～40 分 |
| 1 | 启动软件，新建或打开一张图 | [L1-启动新建与打开](./L1-启动新建与打开.md) | 45～60 分 |
| 2 | 弄清「这张图」里有什么（瓦片与内存起点） | [L2-认识文档与图层](./L2-认识文档与图层.md) | 60～90 分 |
| 3 | 在画布上看到合成结果（投影也占内存） | [L3-画布显示与合成](./L3-画布显示与合成.md) | 60～90 分 |
| 4 | 用画笔等工具改像素（瓦片变多） | [L4-绘制操作](./L4-绘制操作.md) | 60～90 分 |
| 5 | Ctrl+Z / 重做（历史也有字节上限） | [L5-撤销与重做](./L5-撤销与重做.md) | 40～50 分 |
| 6 | 拉选区再编辑 | [L6-选区操作](./L6-选区操作.md) | 45～60 分 |
| 7 | 建层、调序、复制、透明度、混合 | [L7-图层操作](./L7-图层操作.md) | 45～60 分 |
| 8 | 给图层加滤镜（派生缓存） | [L8-滤镜操作](./L8-滤镜操作.md) | 45～60 分 |
| 9 | 钢笔路径、路径与选区互转 | [L9-路径与钢笔](./L9-路径与钢笔.md) | 60～90 分 |

| 考 | 闭卷检验 | [测验-工作流.html](./测验-工作流.html) | 20～30 分 |

主流程是 **L0→L10**（新建到导出）。**L11 可跳过**。页缓存**没有 L12**——跟内存一起嵌在 L2～L5/L7/L8。
