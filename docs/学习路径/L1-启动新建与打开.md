# L1 — 启动 · 新建 · 打开

**用户在干什么：** 打开软件；点「新建」或「打开」得到一张可编辑的图。

**目标：** 跟通 `main` → 窗口 → `AppSession::setDocument` → 各面板收到新文档。

**建议耗时：** 45～60 分钟。  
**前置：** [L0](./L0-工作流总览.md)。

---

## 1. 工作流位置

```text
[本层] 启动 → 新建/打开 → documentChanged
         ↓
       下一层才深挖「文档里面是什么」
```

---

## 2. 代码落点

```text
main()
  opsInit()                     // 算子就绪，后面滤镜/合成才找得到类型
  RasterScheduler::warmUp()     // 异步探 GPU，不挡首帧（细节 L11）
  MainWindow.showMaximized()

用户：新建 / 打开
  MainWindow → 构造 ImageDocument（createBlank / ProjectIo::load / …）
  → AppSession::setDocument(unique_ptr)
  → emit documentChanged(doc)
  → Canvas / 图层面板 / 其它 dock 刷新
```

**内存起点（先记一句）：** `createBlank` 白底会 `fill` → 覆盖范围内瓦片**立刻占满**；透明新层则 **0 块瓦片**。  
「像素何时开始吃内存」的细节在 [L2](./L2-认识文档与图层.md)。

关键不变量：

- **文档唯一持有者**是 `AppSession`（`unique_ptr`）；UI 只观察裸指针。  
- `setDocument` 时**旧文档活到广播结束**（槽里要对旧指针 `disconnect`）。  
- 新面板：**订阅 session**，不要改 MainWindow 里一长串手工 `setDocument`。

打开分支（扫一眼即可）：`.pslite` → `ProjectIo`；位图 → `RasterIo`；PSD → `PsdIo`。存盘细节在 [L10](./L10-保存与导出.md)。

## 4. 必读 / 选读 / 不必读

- `main`、`AppSession`、MainWindow 新建/打开路径  

### 选读

### 不必读

---

## 5. 常见误解

| 误解 | 更正 |
|------|------|
| MainWindow 拥有文档 | 拥有者是 AppSession |
| 打开失败因为没 GPU | 打开走 IO；GPU 只影响加速 |
