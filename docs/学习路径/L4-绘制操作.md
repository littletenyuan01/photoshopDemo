# L4 — 绘制操作

**用户在干什么：** 选画笔/橡皮等，在图上拖拽，改像素。

**目标：** 跟通鼠标 → `ToolManager` → `PaintTool` → `PaintEngine` → tiles → `markDirty`。

**建议耗时：** 60～90 分钟。  
**前置：** [L3](./L3-画布显示与合成.md)。

---

## 1. 工作流位置

```text
看得见画面
  → [本层] 动手改像素
  → 下一层：撤销这次修改
```

---

## 2. 代码落点

```text
CanvasView 鼠标事件
  → makeToolEvent + refreshToolContext
  → ToolManager::dispatch*(event, ctx, ViewPort)
  → PaintTool
       → pushLayerPixelsUndo（先快照！细节 L5）
       → PaintEngine::stampDab / strokeSegment(layer->tiles())
       → markDocumentDirty → doc->markDirty → 回到 L3 刷新链
```

注意：**层坐标**写瓦片，**文档坐标**报脏区。层必须 `allowsPixelEdit()`。

### 2.1 画一笔，内存怎么变？

- `PaintEngine` → `ensureTile`：笔刷碰到的格子才分配 → **触碰面积越大，驻留瓦片越多**。  
- 换页若开启：笔画中途**不** trim（避免持着 `QImage*` 时瓦片被换走）；**抬笔**后 `CanvasView` 静默点才 `TileCache::trim`。  
- 这就是 L2 说的「粗粒度钉住 + 静默点」在真实操作里的落点。
