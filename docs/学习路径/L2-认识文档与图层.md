# L2 — 认识文档与图层

**用户在干什么：** 已经有一张图；要理解「我在编辑的对象」是什么（还没开始猛画）。

**目标：** 说清 `ImageDocument` / `Layer` / `TileBuffer`；像素与属性分别存在哪。

**建议耗时：** 60～90 分钟。  
**前置：** [L1](./L1-启动新建与打开.md)。

---

## 1. 工作流位置

```text
新建/打开成功
  → [本层] 文档真相长什么样
  → 下一层：怎么画到屏幕上
```

调图层顺序/透明度等**操作**在 [L7](./L7-图层操作.md)；本层先建立数据模型。

---

## 2. 代码落点

```text
ImageDocument
  ├─ 宽高、活动层
  ├─ LayerStack
  │    └─ Layer
  │         ├─ TileBuffer m_tiles   ← 像素（64×64 稀疏，ARGB32 预乘）
  │         ├─ FilterStack          ← 滤镜参数（操作见 L8）
  │         └─ offset / 可见 / 不透明度 / 混合…
  ├─ Selection                      ← 选区（操作见 L6）
  ├─ PathStack                      ← 路径（操作见 L9）
  └─ HistoryStack                   ← 撤销（操作见 L5）
```

写像素后要 `markDirty(rect)`，才会进入「看见画面」那条刷新链。

### 2.1 内存从这里开始涨（工作流里第一次讲清）

| 事实 | 含义 |
|------|------|
| 稀疏 | 透明层 hash 空 = 几乎不占像素 RAM；`ensureTile` 才分配 |
| 默认常驻 | 写过的瓦片**默认一直留在内存**（预算 0 = 不换页） |
| 可观测 | `TileBuffer::residentBytes()`；`PSLITE_MEM=1` 打 tiles/undo/projection/swap/peak |
| 大图再开 | `PSLITE_TILE_CACHE_MB>0` 才启用 [页缓存](../page-cache-plan.md)：LRU 换到临时文件；**粗粒度钉住**，不在 `ensureTile` 里淘汰（防 `QImage*` 悬垂） |

读到这里不必啃完换页实现；先建立「**操作越多 → 触碰的格子越多 → RAM 单调涨**」，下一层会看到投影缓冲也要占一份。
