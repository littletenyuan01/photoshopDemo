# L6 — 选区操作

**用户在干什么：** 矩形/套索等拉选区；反选、取消；之后只编辑选中区域。

**目标：** 选区是文档级 mask；工具如何写；蚂蚁线刷新 vs 合成刷新。

**建议耗时：** 45～60 分钟。  
**前置：** [L5](./L5-撤销与重做.md)。

---

## 1. 工作流位置

```text
会绘制、会撤销
  → [本层] 限定编辑范围（选区）
  → 之后：调图层 / 滤镜 / 路径 也可配合选区
```

与路径互转的细节在 [L9](./L9-路径与钢笔.md)；本层建立「选区是 mask」即可。

---

## 2. 代码落点

```text
ImageDocument::selection()
  → Selection（灰度 mask + ChannelOp 组合）
选区工具 → 改 mask → pushSelectionUndo → selectionChanged
CanvasView → 重建蚂蚁线 → update（通常不重跑整页 compositeRegion）
```

Document 上还有 `selectAll` / `clear` / `invert` / 几何选等入口。

## 3b. 深挖 A+B：蚂蚁线刷新链路 & 矩形框写入链路（源码支撑）

### A. 蚂蚁线刷新 —— 为什么"改选区"不重合成

**链路：** `selectXxx` → `emit selectionChanged()` → CanvasView 订阅只做三件事**不碰投影**。

关键在 [canvasview.cpp:195-201](file:///d:/CVlearningProject/gimp/photoshopDemo/psDemo/ui/canvasview.cpp#L195-L201)：
```cpp
// 选区单独订阅：只重画蚂蚁线，不重合成
connect(m_document, &Ps::ImageDocument::selectionChanged, this, [this]() {
    rebuildSelectionOutlinePath();   // 1. 按 mask 重建矩形path(只走边)
    syncMarchingAntTimer();          // 2. 有选区→开100ms定时器，无→停
    update();                        // 3. 只重绘控件(叠蚂蚁线)，不动投影缓存
});
```
对比 `contentChanged`（改像素）才会驱动 `syncProjection()` 重合成。**选区改动走 `selectionChanged`，不是 `contentChanged`** ⇒ 分道：选区只刷新"蚂蚁线叠加层"，不清不重算投影像素。这就是自检题 2「改选区不必然全图重合成」的代码根源。

蚂蚁线本身两段：
- **路径重建**：`m_antsPath` 按 mask 的**边缘 run** 构建（`moveto/lineto`，[canvasview.cpp:1562](file:///d:/CVlearningProject/gimp/photoshopDemo/psDemo/ui/canvasview.cpp#L1562)），选区改了才 rebuild。
- **绘制**：`paintSelectionOutline` 用**黑+白两条错开 6px dash、cosmetic 宽度=1屏幕像素**的虚线叠画成"狂奔蚂蚁"（[canvasview.cpp:1704-1726](file:///d:/CVlearningProject/gimp/photoshopDemo/psDemo/ui/canvasview.cpp#L1704-L1726)），相位 `m_antsPhase` 由 100ms 定时器递增取模 12 驱动动画（[canvasview.cpp:77-82](file:///d:/CVlearningProject/gimp/photoshopDemo/psDemo/ui/canvasview.cpp#L77-L82)）。

### B. 矩形选框写入 —— 鼠标拖动怎么落进 mask

主类是 `MarqueeSelectTool`（矩形/椭圆），[marqueeselecttool.cpp:155-166](file:///d:/CVlearningProject/gimp/photoshopDemo/psDemo/tools/marqueeselecttool.cpp#L155-L166)，**松手时一次性定稿**：
```cpp
const QRectF rf = currentImageRect();          // 文档坐标的拖框
QRect rect(qFloor(rf.left()), qFloor(rf.top()), ...);   // 取整成像素矩形
if (rect.width()<1 || rect.height()<1) return true;     // 零面积不提交(防单击误清空)
if (m_shape == Shape::Ellipse)
    ctx.document->selectEllipse(rect, m_op);   // ChannelOp 组合
else
    ctx.document->selectRectangle(rect, m_op);
```
要点对照 L6 §2：
- **拖的过程中不写 mask**，只在 `release` 把框**取整后一次性提交**（拖动预览在 marquee 浮层画，不落 mask，省撤销条目）。
- `m_op`（`ChannelOp::Add/Subtract/Replace/Intersect`，见 [selection.h:17-23](file:///d:/CVlearningProject/gimp/photoshopDemo/psDemo/domain/selection.h#L17-L23)）决定新框与**已有 mask 如何组合**：Replace=新选区取代、Add=并、Subtract=减、Intersect=交。对应 GIMP GimpChannelOps。
- `selectRectangle` 内部 3 步模板（**先 pushSelectionUndo → 改 mask → emit selectionChanged**），与 selectAll 完全同构（[imagedocument.cpp:1009+](file:///d:/CVlearningProject/gimp/photoshopDemo/psDemo/domain/imagedocument.cpp#L1009)）。

### B2. 三种"套索"/魔棒对照（L6-选区 2b 已有，合并记忆）
`lassotool`(手绘自由点) / `polygonallassotool`(直线段落点,拦Delete) / `magneticlassotool`(吸附边缘) / `quickselecttool`/`magicwandtool`(颜色洪泛)。**四者都只改 mask、都走 pushSelectionUndo** ⇒ 选区自古就轻量、不拷整层像素。

## 5b. 三辨析：mask 本质 / 软边vs羽化 / 二值门控 vs 灰度权重

### 辨析1｜mask 初始状态与取值语义
- **初始 = 全 0（全未选中）**：[selection.cpp:19-29](file:///d:/CVlearningProject/gimp/photoshopDemo/psDemo/domain/selection.cpp#L19-L29) `reset()` 建 `Format_Grayscale8`（与文档同尺寸）+ `fill(0)`；`clear()`(Ctrl+D)也是 `fill(0)`。
- 全选 = `fill(255)`（[selection.cpp:159-161](file:///d:/CVlearningProject/gimp/photoshopDemo/psDemo/domain/selection.cpp#L159-L161)）；矩形/椭圆写入 `=255`。
- 判定"选中"用 `isSelected() = value > 0`（[selection.h:74](file:///d:/CVlearningProject/gimp/photoshopDemo/psDemo/domain/selection.h#L74)），但像素存 0~255 全范围。所以"全 1"应精确说"全 255"。
- **为什么要灰度而非 1bit**：要表达软边/半选中（中间灰度 1~254）。来源见辨析2。

### 辨析2｜软边 vs 羽化（概念 + 工程实际）
- **软边 = 边界处 0→255 渐变**的大概念；**羽化 = 软边的一种实现**（人为给边界加定宽渐变环带，半径=羽化半径，跨越边界内外两侧）。羽化不是只影响"贴着线的那 1 像素"，而是沿轮廓一圈的宽度环。
- **本工程矩形/椭圆选框是硬边、不羽化**：[selection.h:62-63](file:///d:/CVlearningProject/gimp/photoshopDemo/psDemo/domain/selection.h#L62-L63) selectEllipse 注释"本项目不做 antialias / feather（硬边）"。
- **本工程真正的软边来源**：由图层 alpha / 层蒙版灰度插入选区时保留中间值——[selection.cpp:349](file:///d:/CVlearningProject/gimp/photoshopDemo/psDemo/domain/selection.cpp#L349) selectFromLayerAlpha 注释"中间值保留作软边"。

### 辨析3｜画笔怎么用选区：二值门控（不是灰度权重混合）★工程实际
用户在构思"裁剪时软边半混合/半复制"，但画笔路径**并未按灰度加权**，详见 [paintengine.cpp:116-147](file:///d:/CVlearningProject/gimp/photoshopDemo/psDemo/engine/paintengine.cpp#L116-L147)：
```cpp
if (clip.selection && !clip.selection->isEmpty()) {
    const QRect selDoc = clip.selection->bounds();
    ... dabRect = dabRect.intersected(selLocal);   // ① 先拿 bounds 求交缩小绘制矩形
}
for (int y...){ for (int x...){
    if (!clip.selection->isSelected(docX, docY))   // ② isSelected = value>0（布尔门控）
        continue;                                  //    未选中→整格跳过(完全不画)
    const qreal cover = BrushCover::fromDist2(...); // ③ 选中→正常画；边缘渐变来自笔刷硬度，与选区无关
    line[x] = uchar(qRound(oldV + (int(target)-oldV) * cover));
}}
```
结论：
- 画笔裁剪 = **二值门控**：`value>0` 视为"选中"就整格画，soft 边中间灰度(如127)与255**表现相同**，不产生"半混合"。
- 真正产生边缘渐变的是**笔刷硬度 BrushCover**，不是选区灰度。
- **工程简化**：若要让软边真生效，需"把选区灰度当 alpha 混合权重"的加权混合逻辑，当前画笔未实现（用 `isSelected` 吞掉了软边，等价先阈值二值化）。
- 其他工具同：painttool/tonetool/shapetool/clonestamptool/paintbuckettool/gradienttool 都 `assert clip.selection = &doc->selection()`（[painttool.cpp:19-24](file:///d:/CVlearningProject/gimp/photoshopDemo/psDemo/tools/painttool.cpp#L19-L24) 等），走同一门控。
