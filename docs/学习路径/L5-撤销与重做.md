# L5 — 撤销与重做

**用户在干什么：** Ctrl+Z / Ctrl+Y，回到上一步编辑结果。

**目标：** 说清 `HistoryStack`、Undo 条目类型、先 push 再改；菜单如何订阅。

**建议耗时：** 40～50 分钟。  
**前置：** [L4](./L4-绘制操作.md)。

---

## 1. 工作流位置

```text
刚完成一次编辑（绘制/后面的选区·图层·滤镜·路径）
  → [本层] 撤销服务贯穿之后所有操作
```

学完本层后，后面每学一种操作，都问一句：「对应哪种 `push*Undo`？」

---

## 2. 代码落点

```text
ImageDocument
  └─ HistoryStack   push / undo / redo / 内存修剪
       UndoItem 种类：像素、属性、结构、选区、路径、几何、滤镜…
changed → MainWindow 刷新撤销菜单
```

入口在 Document：`pushLayerPixelsUndo`、`pushSelectionUndo`、`pushPathUndo`…  
**铁律：先 push（改前快照），再改真相。**
