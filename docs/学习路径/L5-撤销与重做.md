# L5 — 撤销与重做

**用户在干什么：** Ctrl+Z / Ctrl+Y，回到上一步编辑结果。

**目标：** 说清 `HistoryStack`、Undo 条目类型、先 push 再改；菜单如何订阅。

**建议耗时：** 40～50 分钟。  
**前置：** [L4](./L4-绘制操作.md)。

---

## 1. 工作流位置

```text
刚完成一次编辑（绘制/后面的选区·图层·滤镜·路径）
  → [本层] 撤销服务贯穿之后所有操作
```

学完本层后，后面每学一种操作，都问一句：「对应哪种 `push*Undo`？」

---

## 2. 代码落点

```text
ImageDocument
  └─ HistoryStack   push / undo / redo / 内存修剪
       UndoItem 种类：像素、属性、结构、选区、路径、几何、滤镜…
changed → MainWindow 刷新撤销菜单
```

入口在 Document：`pushLayerPixelsUndo`、`pushSelectionUndo`、`pushPathUndo`…  
**铁律：先 push（改前快照），再改真相。**

### 2.1 两种「内存上限」，别混

| 机制 | 管什么 | 超限怎么办 |
|------|--------|------------|
| `HistoryStack` 字节上限（默认 ~256MB，`setByteLimit`） | **撤销条目** | 丢**最老** undo（可撤步数变少）；发 `historyTrimmed` |
| `TileCache`（`PSLITE_TILE_CACHE_MB`，默认 0=关） | **图层瓦片驻留** | 脏写 swap，干净直接丢内存副本；需要时再读回 |

push 之后也是静默点之一：`HistoryStack::push` 末尾可 `TileCache::trim`。  
**不做**「undo 瓦片化」（把历史也换成页缓存引用）——计划 C 档明确否掉；可调上限 + 提示更划算。
