# L8 — 滤镜操作

**用户在干什么：** 给当前图层加滤镜、调参数、看预览，满意后定稿（非破坏栈上的节点）。

**目标：** 滤镜挂在 `Layer::FilterStack`；合成/求值时出效果；预览可异步。  
**本层不讲 GPU**——加速是 [L11](./L11-进阶-GPU加速.md)。

**建议耗时：** 45～60 分钟。  
**前置：** [L7](./L7-图层操作.md)、[L3](./L3-画布显示与合成.md)。

---

## 1. 工作流位置

```text
图层已可调
  → [本层] 加非破坏滤镜看效果
  → 存盘时参数写入工程（L10）；跑得快慢可看 L11
```

---

## 2. 代码落点

```text
Layer::FilterStack（FilterNode 参数）
  → 合成/求值：FilterEval（必要时 RasterScheduler::runStack）
  → 结果进复合缓存；未「栅格化」则不永久烤进 tiles
异步：LayerFilterJob + markDirtyQuiet（预览）
```

菜单哪些已接线：[filter-roadmap.md](../filter-roadmap.md)。

### 2.1 滤镜结果缓存：可丢、可重算

- `Layer::m_regionFilterImage` 是**单槽**区域结果：命中则投影合成少算一遍滤镜。  
- 内存吃紧且换页开启时，`TileCache::trim` **会先清这类派生缓存**（丢掉还能再算，正确性风险 ≈ 0），再考虑换出瓦片。  
- 这与「tiles 真相不能随便扔」形成对照——工作流走到滤镜时，内存故事才完整。
