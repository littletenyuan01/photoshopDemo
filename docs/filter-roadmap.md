>

## 1. 一句话结论

已做的 14 项覆盖了「模糊 / 锐化 / 杂色 / 其它」四类的骨干，且已建立**算子模板**
（`FilterOp` 三段式 + 注册表 + 参数页 + 菜单 + oracle 用例）。
剩下未做项里：

- **8 项批次 A**：纯复用 / 轻量组合（优先）；
- **已有增强轨 A′**：动感模糊任意角等（不增菜单项，补齐已接线能力）；
- **几何重映射 B**：先做 2～3 个代表项验证 ROI，不一口气承诺 9 项；**置换**单独成档（双输入）；
- **C1 轻量邻域** / **C2 重项后置**；
- **D 确定性随机**；
- **E 明确不做**（含原孤儿：彩色半调 / 彩块化 / 防抖）；
- **F 清理占位符**。

## 3. 优先级判断标准

| 维度 | 说明 |
|---|---|
| **成本** | ① 纯复用 < ② 套模板新算子 < ③ 新参数类型/双输入 < ④ 交互、预设、生成器 |
| **收益** | 日常使用频率（模糊/锐化/杂色 > 扭曲展示项 > 渲染） |
| **风险** | 是否引入新概念（位置相关、几何重映射、双输入）。复用现成机制，勿另造 |
| **验证成本** | 有数学定义 ⇒ 朴素 oracle；无参考 ⇒ 人眼（贵） |

**硬纪律**：任何新算子必须带**朴素 oracle** + **分块投影 == 整幅合成**断言
（见 `pending-dev.md` 缺陷台账 #16/#20）。

## 4. 分档与建议批次

### 批次 A —— 纯复用 / 轻量组合，**8 项**（**先做**）

| 项 | 实现 | 成本 |
|---|---|---|
| 模糊 | 盒模糊 r=1，直接应用 | ① |
| 进一步模糊 | 盒模糊 r=2，直接应用 | ① |
| 锐化 | 现有锐化强度=1，直接应用 | ① |
| 去斑 | 中值 r=1，直接应用 | ① |
| 曝光过度 | 新增点算子 Solarize | ① |
| 减少杂色 | Demo：中值 + 强度混合（对话框） | ② |
| 蒙尘与划痕 | Demo：中值 + 阈值（对话框） | ② |
| 锐化边缘 | Sobel 幅值 mask × 锐化（对话框） | ② |

**验收**：复用项与现成算子同参逐像素一致；其余各带 oracle。  
**目标**：菜单已接线 14 → 22。

### 批次 A′ —— 已有增强（不增菜单项）✅

| 项 | 说明 |
|---|---|
| 动感模糊任意角度 | ✅ 0°/90° 一维盒，其余角沿方向最近邻取样平均 |
| （可选）自定 5×5 / 位移 wrap | 见 `pending-dev.md`，后置 |

### 批次 B —— 几何重映射（**代表项先做，勿一次 9 项**）

**已完成代表**：波纹（水平正弦位移，`hasPositionalOp` 整层路径）。  
**其余候选**（不必做满）：极坐标、球面化（或挤压）。  
共性：`out(x,y)=in(f(x,y))`；可分块者 `requiredInputs` 取 `f(输出区)` 包围盒。

**共同风险**：雅可比 > 1 时包围盒放大；须断言分块==整幅；过大则退化整层。

### 批次 B′ —— 双输入几何（置换）

置换需要**第二张位移图**（层/文档选择 + 序列化），成本 ③～④，**不要**与 B 混排。

### 批次 C1 —— 轻量邻域，**约 8 项**

径向模糊、表面模糊、特殊模糊、马赛克、碎片、等高线、风、拼贴（+ 可选上次滤镜）。  
套模板；每项约 15–40 分钟量级（含 oracle）。

### 批次 C2 / 并入 E —— 偏重，**不按 15 分钟估**

形状模糊、镜头模糊、智能锐化、凸出 → **默认进 E**，改主意须在本文件写理由。

### 批次 D —— 确定性随机，**5 项**

晶格化、点状化、铜版雕刻、扩散、油画。  
复用「添加杂色」的 `(x,y,seed)` 散列 + `hasPositionalOp` 整层路径。

### 批次 E —— 不做（**明确记录理由**）

| 项 | 理由 |
|---|---|
| 云彩 / 分层云彩 / 纤维 / 镜头光晕 / 光照效果 | 生成器，无「输入图」语义 |
| 液化 / 消失点 / 模糊画廊 | 交互式工具 |
| 滤镜库 / Camera Raw / 自适应广角 / 镜头校正 / 浏览滤镜 | 预设 / 专业 / 在线 |
| 转换为智能滤镜 | 本工程本就非破坏 |
| 镜头模糊 / 凸出 / 智能锐化 / 形状模糊 | 成本与收益不成比例 |
| **彩色半调 / 彩块化 / 防抖** | 重；原清单孤儿，归入不做 |

### 批次 F —— 待确认 / 清理

| 项 | 处置 |
|---|---|
| `actionFilterDistort` | 确认后删除或改名 |
| `actionFilterNoise` | 与添加杂色重复 → 删除或别名 |

## 6. 每批的通用交付清单（模板）

1. 算子：`engine/op/<name>filterop.{h,cpp}`（或并入 `filtereval.cpp` 的点算子表）；
2. `OpName` 追加到 **`Count` 之前**（`.pslite` 存枚举整数值，插中间会让旧文件错位）；
3. `FilterNode` 加参数字段 + `inputPad()` / `requiredInputs()`；
4. `opsinit.cpp` 注册（有临时资源走 `FilterOp`；纯点算子走 `applyPointNode`）；
5. `.pslite` 参数**尾部追加**（固定块布局，勿动已有顺序）；
6. **参数页**：像素滤镜在 `FilterDialog` / `adjustmentpropshost.cpp` 的**程序化建页**（不是 `.ui` 调整层页）；菜单接线在 `mainwindow.cpp`；
7. 测试：朴素 oracle + **分块投影 == 整幅** + 参数往返；
8. 文档：`features.md`、`tests.md`、`pending-dev.md`、**本文件状态列**；
9. `app.pri` / `tests.pro` 登记新文件。

> 模板已跑过多轮（自定、最大/最小、高通、运动模糊、添加杂色）。  
> **轻量邻域**实测约 15–40 分钟/项；**镜头模糊级**勿套用该数字。
