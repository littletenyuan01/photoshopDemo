## 怎么打开

双击 `index.html`。左上角是 **5 个步骤**（也可以按 `←` `→`），画布可以直接拖动画笔。

## 5 步各讲一件事

| 步 | 一句话 | 你会看到 |
|---|---|---|
| 1 | 一张图不是一整块，是**切成格子** | 虚线格 = 地址在、数据没分配；**格子锚在图像原点，不随视口移动**；蓝框 = 视口，青框 = 这一屏要读的格子 |
| 2 | **只画过的地方才有格子**（稀疏，没写过 = 0 字节） | 数字面板"已分配 X / 12 格" |
| 3 | **每个图层各自一套格子**（并排，不是嵌套） | 每层的"格子数"各自增长 |
| 4 | 你看到的 = **叠起来后算出的第三份数据** | 自底向上叠加动画 |
| 5 | 改一小块**只重算那一小块**（脏格子） | 红框 = 刚重算的格子；可切"整幅重算"对照 |

每步右下角都有一个**示范按钮**（"画一笔示范""重播叠加动画"…），点一下就能看到动作，不必自己摸索。

## 只有三组控件

1. **工具**：画笔 / 橡皮（只作用于活动图层）
2. **格子粒度**：64 / 128 / 256（同一笔碰到的格子数会变）
3. **改一块之后**：只重算脏格子 ↔ 整幅重算（对照用）

## 老实说

- 页面里跑的是**真实像素数组**（预乘 alpha，合成公式 `out = src + dst × (1 − srcA)`），
  数字都是当场算的；
- 资料分级：`[官方]` 官方文档可查 · `[共识]` 业界共识（**128×128 格子没有官方文档**）·
  `[源码]` GIMP 可逐条核对（`gimptilehandlervalidate.c` / `gimpprojection.c`）；
- 有意简化：颜色运算内部用 float32；页面上算的"字节数"按 8 位/通道（4 B/px）计；
  演示文档固定 512×384；不含暂存盘/位深/边缘瓦片等进阶内容（那些在 02）。
